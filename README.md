# 🎂 Happy Birthday Divya ♥ — Interactive Birthday Surprise Website

An elegant, animation-driven interactive birthday surprise website built with pure HTML5, CSS3, JavaScript, SVG, and Canvas.

---

## ✨ Features
1. **Interactive Bow & Arrow**: Pointer events with elastic drag, spring vibration, and dynamic heart trajectory targeting.
2. **Impact & Particle Burst**: Squash/shake impact with cascading mini rose-gold hearts, daisy petals, and stardust sparks.
3. **Cinematic Twilight Plum Banner**: Widescreen letterbox reveal with flickering candle star flare and personal dedication to Divya.
4. **Enchanted Blooming Heart Tree**: Organically growing trunk, skeletal heart branches, and 650+ blossoms in Twilight Lavender & Rose Gold harmony, accompanied by pulsing fairy fireflies.
5. **Interactive Second Pull Message**: An animated "PULL & RELEASE" ribbon trigger with hand icon guidance.
6. **Secret Love Letter Modal**: A frosted glassmorphism card containing heartfelt wishes, customizable greetings, and replay options.
7. **Romantic Audio**: Soundtrack with audio toggle controls and automatic unlock.

## 🚀 How to Deploy on Render (100% Free, 2 Minutes)

### Step 1: Push to GitHub
1. Create a new repository on [GitHub](https://github.com/new) (e.g. `divya-birthday-surprise`).
2. Run these commands in your project folder:
   ```bash
   git init
   git add .
   git commit -m "Happy Birthday Divya surprise website"
   git branch -M main
   git remote add origin https://github.com/YOUR_USERNAME/divya-birthday-surprise.git
   git push -u origin main
   ```

### Step 2: Deploy on Render
1. Go to [Render Dashboard](https://dashboard.render.com).
2. Click **New +** and select **Static Site**.
3. Connect your `divya-birthday-surprise` GitHub repository.
4. Fill in the settings:
   - **Name**: `divya-birthday` (or any name)
   - **Branch**: `main`
   - **Build Command**: *(leave blank/empty)*
   - **Publish Directory**: `.`
5. Click **Create Static Site**.

Render will deploy your site in less than 30 seconds and give you a live public link like:
`https://divya-birthday.onrender.com`
